# BRD: Скрипт приветствия `tools/greet.sh`

**Тип:** improve · **Tier:** small

---

## Problem Statement

`tools/greet.sh` читает имя из `config/name.txt` и печатает приветствие. Сейчас
при отсутствующем файле конфигурации он молча печатает приветствие с пустым
именем и возвращает нулевой код — вызывающая сторона не может отличить успешный
прогон от неудачного.

## Goals

Отсутствие файла конфигурации становится явной ошибкой: ненулевой код возврата и
сообщение в stderr.

## Non-Goals

- Создание файла конфигурации за пользователя.
- Любые изменения формата приветствия при наличии файла.

---

## User Stories

### US-1 — Отсутствие конфигурации видно вызывающей стороне

**Как** вызывающий скрипт, **я хочу** получить ненулевой код возврата при
отсутствии `config/name.txt`, **чтобы** не принять пустое приветствие за
успешный результат.

**Acceptance Criteria:**
- AC-1.1 При отсутствующем `config/name.txt` код возврата ненулевой.
- AC-1.2 При отсутствующем `config/name.txt` в stderr выводится сообщение,
  называющее отсутствующий путь.
- AC-1.3 При наличии `config/name.txt` поведение прежнее: код 0 и приветствие
  `Hello, <имя>!` в stdout.

---

## Business Rules

| # | Правило |
|---|---|
| BR-1 | Пустое имя никогда не печатается как успешное приветствие. |
| BR-2 | Сообщение об ошибке идёт в stderr, не в stdout. |

---

## Acceptance (issue level)

1. Прогон без `config/name.txt` даёт ненулевой код и сообщение в stderr.
2. Прогон с `config/name.txt`, содержащим `World`, печатает `Hello, World!` и
   возвращает 0.
