# Test Plan: Фикстур-issue для пустого предмета ревью

**Date:** 2026-08-12

## Overview

Один кейс. Он существует, чтобы у этой фикстур-issue был полный набор
планировочных документов и проверка входных условий стадии код-ревью прошла — а
остановка произошла именно на пустом диффе, а не раньше, на недостающем
документе.

## Prerequisites

- Ветка задачи создана, но ни одного коммита с изменениями поверх родительской
  ветки в неё не добавлено.

## Test Cases

### TC-001: Пустой предмет ревью останавливает стадию явной ошибкой

**Description:** При пустом диффе стадия код-ревью обязана остановиться с явной
ошибкой и не записать вердикт об успешном прохождении.

**Preconditions:**
- Ветка задачи существует и не содержит изменений относительно родительской.

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Запустить проверку кода на этой задаче. | Стадия останавливается, сообщая, что ревьюить нечего. |
| 2 | Прочитать сообщение об остановке. | Формулировка отличима от результата «отревьюено, замечаний нет». |
| 3 | Проверить отчёт стадии. | Вердикта об успешном прохождении в нём нет. |

**Требуемые данные:**
- `config/app.conf` не требуется — предмет проверки в отсутствии изменений

**Expected Outcome:** Пустой предмет ревью не засчитывается как чистый результат.

**Priority:** Critical
