# Business Requirements Document: Фикстура «документ вне ветки задачи»

**Date:** 2026-08-12

## Overview

Небольшой документ с требованиями, специально оставленный на общей ветке
разработки без отдельной ветки задачи — воспроизводит ситуацию, когда
проверка документа запускается до того, как для issue создана
собственная ветка.

## Problem Statement

Нужен инструмент, который печатает приветствие пользователю по имени,
взятому из конфигурационного файла.

## User Stories

### US-1: Приветствие по имени из конфигурации

**As a** пользователь инструмента,
**I want** увидеть персональное приветствие,
**So that** я вижу подтверждение, что конфигурация подхвачена верно.

**Acceptance Criteria:**
- AC-1.1: Если конфигурационный файл присутствует и содержит имя — печатается `Hello, <имя>!`.
- AC-1.2: Если конфигурационный файл отсутствует — печатается явное сообщение об ошибке, а не пустое приветствие.

## Non-Goals

- Поддержка нескольких языков приветствия — вне объёма.

## Acceptance (issue-level)

Обе AC из US-1 проверяемы вручную; инструмент — единственный файл, без
зависимостей.
