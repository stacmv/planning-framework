# Test Plan: Утилита конфигурации `lib/config.sh` / `bin/run.sh`

**Date:** 2026-08-12

## Overview

Четыре тест-кейса, по одному на задачу плана реализации выше.

## Test Cases

### TC-001: `load_config()` — путь конфига и ошибка при отсутствующем файле

**Description:** `load_config()` читает `config/app.conf` от корня репозитория; при отсутствии файла — ошибка, не тихий пропуск.

**Preconditions:** Нет `config/app.conf` для первой проверки; есть — для второй.

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Запустить `bin/run.sh` без `config/app.conf`. | Ненулевой код возврата, сообщение об ошибке в stderr. |
| 2 | Запустить `bin/run.sh` с `config/app.conf`, содержащим `host=localhost`. | Значение `host` читается корректно. |

**Expected Outcome:** Отсутствие конфига — явная ошибка.

**Priority:** Critical

### TC-002: `get_value()` — предупреждение о неизвестном ключе

**Description:** Запрос отсутствующего ключа возвращает пустую строку и печатает предупреждение в stderr.

**Preconditions:** Конфиг загружен, не содержит ключ `missing_key`.

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Вызвать `get_value missing_key`. | Пустая строка на stdout, предупреждение в stderr. |

**Expected Outcome:** Неизвестный ключ виден в выводе, не проглатывается молча.

**Priority:** High

### TC-003: `bin/run.sh` — валидация вызывается перед использованием значений

**Description:** Точка входа обязана вызвать `validate_config()` после `load_config()` и до первого `get_value()`.

**Preconditions:** Нет.

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Запустить `bin/run.sh` с конфигом, не содержащим обязательный ключ `port`. | Останавливается на валидации, не доходит до использования значений как валидных. |

**Expected Outcome:** Невалидный конфиг перехватывается до использования.

**Priority:** Critical

### TC-004: `validate_config()` — отсутствующий обязательный ключ называется явно

**Description:** При отсутствии обязательного ключа — сообщение называет конкретный ключ, ненулевой код возврата.

**Preconditions:** Конфиг без ключа `host`.

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Вызвать `validate_config()` на конфиге без `host`. | Сообщение называет `host`, ненулевой код возврата. |

**Expected Outcome:** Валидация не проходит молча — называет причину.

**Priority:** High
