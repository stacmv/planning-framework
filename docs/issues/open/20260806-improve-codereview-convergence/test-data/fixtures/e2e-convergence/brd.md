# BRD: Загрузка и валидация конфигурации приложения

**Тип:** improve · **Tier:** small

---

## Problem Statement

`lib/config.sh` загружает key=value конфиг из `config/app.conf`, `bin/run.sh` —
точка входа. Сейчас ошибки конфигурации проходят молча: отсутствующий файл,
неизвестный ключ и невалидное значение одинаково приводят к запуску с пустыми
или частичными настройками, и вызывающая сторона узнаёт об этом только по
странному поведению приложения.

Это фикстур-issue для сквозного прогона цикла код-ревью — не настоящая рабочая
задача.

## Goals

Каждая ошибка конфигурации обнаруживается на загрузке и сообщается явно, до
того как приложение начнёт работу.

## Non-Goals

- Изменение формата конфигурационного файла.
- Значения по умолчанию для отсутствующих ключей.

---

## User Stories

### US-1 — Отсутствующий или нечитаемый конфиг останавливает запуск

**Как** оператор, **я хочу** видеть явную ошибку при отсутствующем
`config/app.conf`, **чтобы** не получить запуск с пустыми настройками.

**Acceptance Criteria:**
- AC-1.1 Отсутствующий файл конфигурации даёт ненулевой код возврата и
  сообщение в stderr, называющее ожидавшийся путь.
- AC-1.2 Путь к файлу берётся из одного места, а не собирается заново в каждой
  функции.

### US-2 — Неизвестный ключ и невалидное значение не проходят молча

**Как** оператор, **я хочу**, чтобы неизвестный ключ и невалидное значение были
названы при загрузке, **чтобы** опечатка в конфиге не превращалась в тихо
неверное поведение.

**Acceptance Criteria:**
- AC-2.1 Неизвестный ключ вызывает предупреждение с именем ключа.
- AC-2.2 Валидация конфигурации выполняется реально, а не объявлена пустой
  функцией.
- AC-2.3 Валидация вызывается на пути загрузки, а не только определена.

---

## Business Rules

| # | Правило |
|---|---|
| BR-1 | Приложение не стартует с частично загруженной конфигурацией. |
| BR-2 | Все диагностические сообщения идут в stderr. |

---

## Acceptance (issue level)

1. Запуск без `config/app.conf` останавливается с ненулевым кодом и внятным
   сообщением.
2. Неизвестный ключ в конфиге виден оператору при запуске.
3. Невалидное значение известного ключа останавливает запуск.
