# Technical Spec: Sort Task List by Date

## 1. Overview

Добавляем сортировку списка задач по дате создания. Пользователь может
переключать порядок (сначала новые / сначала старые) переключателем над
списком.

## 2. Sorting field

Сортировка идёт по полю `updated_at`. TODO: уточнить, нужно ли отдельное
поле `created_at`, или `updated_at` достаточно для обоих режимов
сортировки.

## 3. UI

Переключатель — два радио-баттона над таблицей задач: "Сначала новые" /
"Сначала старые". Состояние переключателя не сохраняется между сессиями.
