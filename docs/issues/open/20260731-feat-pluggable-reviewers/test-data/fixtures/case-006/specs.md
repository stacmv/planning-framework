# Technical Spec: Sort Task List by Date

## 1. Overview

Добавляем сортировку списка задач по дате создания. Сортировка
применяется только на клиенте, без обращения к серверу.

## 2. Sorting field

Сортировка идёт по полю `created_at`, которое сервер отдаёт в каждом
объекте задачи через API `/api/tasks`.

## 3. UI

Переключатель — два радио-баттона над таблицей задач: "Сначала новые" /
"Сначала старые". При переключении фронтенд повторно запрашивает
`/api/tasks?sort=created_at&order=desc` (или `asc`) у сервера — сортировка,
вопреки §1, на самом деле происходит на сервере, а не на клиенте.
