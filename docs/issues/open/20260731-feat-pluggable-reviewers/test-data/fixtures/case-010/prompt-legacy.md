Тестовый «старый» issue (создан как будто до появления поля `reviewers`),
дошедший до конца IMPLEMENT. `/pf`, запущенный на нём, должен предложить
следующим шагом `/pf-codereview` — несмотря на отсутствие `reviewers` —
используя дефолт `claude`.

Добавить сортировку по дате в списке задач.
