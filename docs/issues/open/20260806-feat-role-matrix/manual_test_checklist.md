## Как пользоваться этим чек-листом

Этот чек-лист проверяет функциональность инструмента планирования Claude
Code (плагин-скиллы вида `/pf-...`), а не отдельное пользовательское
приложение. Тестировщику нужен доступ к Claude Code сессии в этом
репозитории и базовое знакомство со slash-командами — без этого шаги ниже
выполнить нельзя, поэтому команды и имена файлов конфигурации приводятся
как есть, а не описываются обходными формулировками.

1. Прочитайте весь раздел теста перед началом, чтобы понимать, чего
   ожидать.
2. Выполните все предварительные условия, указанные вверху раздела — если
   какое-то из них не удаётся выполнить, остановитесь и спросите
   разработчика, прежде чем продолжать.
3. Выполняйте шаги по порядку. После каждого шага сверьтесь со столбцом
   «Ожидаемый результат» и запишите, что произошло на самом деле, в
   столбец «Результат».
4. Отмечайте чекбокс `[x]`, если шаг прошёл как ожидалось, или оставляйте
   `[ ]`, если что-то пошло не так.
5. Используйте строку «Заметки» внизу каждого теста, чтобы записать что-то
   необычное, даже если тест прошёл успешно.
6. Когда закончите все тесты, верните этот документ разработчику.
