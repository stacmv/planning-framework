Баг-репорт, полученный от другого проекта, использующего Planning Framework:
`/pf-test-plan` породил тест-план, чьи тест-кейсы принципиально не
отслеживаются последующей стадией `/pf-test` — то есть `/pf-test` не находит
или не обновляет статус этих TC при прогоне.

Нужно разобраться, почему TC из сгенерированного `test_plan.md` выпадают из
отслеживания в `/pf-test` (несовпадение формата/ID тест-кейсов, разный
парсинг заголовков, отсутствие Status Tracker для части TC и т.п.), и
починить связку `/pf-test-plan` → `/pf-test` так, чтобы каждый TC,
произведённый `/pf-test-plan`, гарантированно отслеживался `/pf-test`.

Источник репорта: сессия Claude Code в другом проекте, во время работы над
`20260806-feat-role-matrix` этой issue.
