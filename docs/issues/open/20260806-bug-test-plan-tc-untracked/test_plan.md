# Test Plan: TC из `/pf-test-plan` не отслеживаются в `/pf-test`

**Issue:** 20260806-bug-test-plan-tc-untracked
**Тип:** bug · **Tier:** small
**Источник:** `analysis.md`

---

## Обзор и цели

`analysis.md` фиксирует три независимых дефекта связки `/pf-test-plan` →
`/pf-test` (Д1, Д2, Д3) и один производный (Д4). Цель фикса — сделать так,
чтобы любой TC, который `/pf-test-plan` пометил `Auto`, был гарантированно
найден и корректно проставлен `/pf-test`, независимо от того, на каком языке
(JS/Python или bash-конвенция этого репозитория) написан покрывающий его
тест, и независимо от того, изменён ли файл теста в текущей ветке.

Задачи этого тест-плана:

- проверить, что каждый из трёх независимых дефектов (Д1 — сканирование не
  покрывает bash-конвенцию репозитория; Д2 — незамкнутая ветка Phase 4 →
  Phase 5; Д3 — область поиска Phase 3.1 ограничена диффом ветки) закрыт
  явным, механически проверяемым правилом в тексте `pf-test/SKILL.md` (и,
  где уместно, `pf-test-plan/SKILL.md`);
- проверить, что ранее работавшие JS/Python-конвенции обнаружения TC-ID не
  сломаны фиксом (регрессия);
- проверить сцепку целиком: TC, объявленный `Auto` в `/pf-test-plan`, реально
  находится и получает статус в `/pf-test` при живом прогоне — то есть
  явление, названное в заголовке issue, устранено не только в тексте
  инструкции, но и в поведении.

Большая часть фикса — правки текста двух `SKILL.md`-файлов, поэтому
большинство TC ниже — `Auto`-проверки присутствия/формулировки конкретных
правил в этом тексте (аналог `TC-009` из `test/skills-role-matrix-static.sh`
для `pf-roles/SKILL.md`). `Manual` оставлен только для одного кейса — реального
сквозного прогона `/pf-test` в живой сессии, потому что только так можно
подтвердить, что агент действительно интерпретирует новое правило так, как
задумано, а не просто то, что правило присутствует в тексте.

## Предпосылки (Prerequisites)

  правлены в рамках `implementation_plan.md` этой issue.

  `/home/stac/dev/planning-framework` (сами `Auto`-проверки — `grep`/`wc` по

  `/pf-update` или эквивалент), доступна интерактивная сессия Claude Code в
