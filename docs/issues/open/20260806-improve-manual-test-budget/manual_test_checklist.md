## How to use

Этот чек-лист проведёт вас по ручной проверке логики 3-вариантного гейта `AskUserQuestion` (Step 4d в `skills/pf-test-plan/SKILL.md`) при превышении Manual-кейсов после automation pass.

1. Прочитайте каждый раздел целиком перед началом.
2. Выполните предусловия, перечисленные в начале каждой проверки — если что-то выполнить не удаётся, остановитесь и сообщите разработчику.
3. Выполняйте шаги по порядку. После каждого шага сверьтесь с ожидаемым результатом и запишите, что произошло на самом деле, в колонку «Результат».
4. Ставьте `[x]` при успехе и `[ ]`, если что-то пошло не так.
5. Строку «Заметки» в конце каждой проверки используйте для всего необычного.
6. Закончив все проверки, верните этот документ разработчику.

## TC-011: Гейт — вариант «Разбить issue»

**Description:** Проверяет, что при выборе пользователем варианта «Разбить issue» в 3-вариантном гейте система корректно регистрирует это решение в `test_plan.md` с рекомендацией о разбиении и перечислением лишних кейсов.

**Prerequisites:**
- Framework репо (`planning-framework/`) готов к запуску `/pf-test-plan`.
- Команда `/pf` доступна (проверить: `which pf` или просто запустить `/pf` в сессии Claude Code).
- Тестовый issue создан в `docs/issues/open/` на основе fixture'а для TC-011 (путь: `test/fixtures/manual-budget-tc-011/` или создан вручную с `size_tier: medium` в `prompt.md` и 5 Manual-кейсами в черновике `test_plan.md` таких, что automation pass не решит проблему полностью).
- Черновой `test_plan.md` содержит достаточно Manual-кейсов, чтобы их число превышало бюджет Medium (>3) даже после возможной конвертации.

**Test Data:**
- `test/fixtures/manual-budget-tc-011/brd.md` — fixture с описанием для issue (или equivalent, созданный вручную).
- `test/fixtures/manual-budget-tc-011/prompt.md` — fixture с `size_tier: medium`.
- `test/fixtures/manual-budget-tc-011/test_plan.md` — черновик тест-плана с Manual-кейсами.

**Steps:**

| Step | Action | Expected Result | Result |
|------|--------|-----------------|--------|
| 1 | Перейдите в каталог issue и запустите `/pf-test-plan` (или продолжите с `/pf` если issue уже выбран). | Skill проверяет Manual-кейсы: найденное число > бюджета tier (например, 5 > 3 для Medium). Гейт срабатывает с сообщением о превышении. | [ ] |
| 2 | Дождитесь появления `AskUserQuestion` с 3 вариантами (Split / Raise tier / Defer). | Вопрос задан явно; все три варианта видны и доступны для выбора. | [ ] |
| 3 | Выберите вариант 1: «Split the issue». | Выбор зарегистрирован; гейт не требует дополнительного ввода. | [ ] |
| 4 | Дождитесь завершения skill. | Skill завершилась успешно без ошибок; сообщена кратко об успешном завершении. | [ ] |
| 5 | Откройте финальный `test_plan.md` и найдите примечание о разбиении. | В `test_plan.md` добавлено примечание (например, абзац выше Status Tracker или в отдельной секции), которое указывает, что рекомендуется разбить issue и перечисляет, какие кейсы являются лишними. | [ ] |
| 6 | Проверьте точность перечисления лишних кейсов. | Примечание правильно называет те кейсы, число которых превышает бюджет (например, если Manual-кейсов 5 при бюджете 3, то названы последние 2 или выделена группа, составляющая избыток). | [ ] |
| 7 | Убедитесь, что Status Tracker сам по себе не изменился. | Статус кейсов (Auto/Manual) остался прежним; гейт добавил только примечание, не переводя кейсы. | [ ] |

## TC-012: Гейт — вариант «Поднять tier»

**Prerequisites:**
- Framework репо готов к запуску `/pf-test-plan`.
- Команда `/pf` доступна.
- Тестовый issue создан на основе fixture'а для TC-012 (путь: `test/fixtures/manual-budget-tc-012/`) или вручную с `size_tier: medium` в `prompt.md` и Manual-кейсами, которые даже после automation pass превышают бюджет Medium (например, 5 Manual-кейсов).
- Черновой `test_plan.md` содержит достаточно Manual-кейсов, чтобы их число превышало текущий tier-бюджет.

**Test Data:**
- `test/fixtures/manual-budget-tc-012/brd.md` — fixture с описанием.
- `test/fixtures/manual-budget-tc-012/prompt.md` — fixture с `size_tier: medium`.
- `test/fixtures/manual-budget-tc-012/test_plan.md` — черновик с Manual-кейсами.

**Steps:**

| Step | Action | Expected Result | Result |
|------|--------|-----------------|--------|
| 1 | Запустите `/pf-test-plan` на issue. | Гейт срабатывает с сообщением о превышении Manual-кейсов (например, 5 > 3 для Medium). | [ ] |
| 2 | Дождитесь `AskUserQuestion` с 3 вариантами. | Вопрос задан; все три варианта доступны. | [ ] |
| 3 | Выберите вариант 2: «Raise the tier». | Система запрашивает обоснование для подъёма tier-а (вторая `AskUserQuestion` или текстовое поле). | [ ] |

| 8 | Проверьте, что Manual-кейсы теперь в бюджете. | Если новый tier имеет бюджет ≥5, то 5 Manual-кейсов укладываются в бюджет; гейт не срабатывает повторно. | [ ] |
