## How to use

Этот чек-лист проведёт вас через ручную проверку одной функции.

1. Прочитайте каждый раздел целиком, прежде чем начинать, — так вы будете знать, чего ожидать.
2. Подготовьте всё, что перечислено в «Предусловиях» вверху теста. Если предусловие выполнить не удаётся — остановитесь и спросите разработчика, прежде чем продолжать.
3. Выполняйте шаги по порядку. После каждого шага сверьтесь с колонкой «Ожидаемый результат» и запишите, что произошло на самом деле, в колонку «Результат».
4. Отмечайте галочку `[x]`, если шаг отработал как ожидалось, или оставляйте `[ ]`, если что-то пошло не так.
5. В строке «Заметки» внизу теста фиксируйте всё необычное, даже если тест прошёл.
6. Закончив все тесты, верните этот документ разработчику.

## TC-006: Закрытие задачи — реальное слияние и непустое окно расхода

**Предусловия:**
- Есть задача, готовая к закрытию (проверка качества по ней пройдена, вердикт PASS).
- Рабочая ветка этой задачи имеет «восходящую» ветку, указывающую сама на себя (как получается после обычной первой публикации ветки командой публикации с флагом отслеживания). Именно этот случай раньше ломал определение родительской ветки.
- Установлен рабочий инструмент, выполняющий процедуру закрытия задачи.
- Доступны локальные журналы работы (для подсчёта окна расхода).

**Требуемые данные:** не требуются

**Steps:**

| Step | Action | Expected Result | Result |
|------|--------|-----------------|--------|
| 1 | Запустить процедуру закрытия задачи и подтвердить закрытие | Все этапы проходят без ошибок | [ ] |
| 2 | Посмотреть историю основной ветки: `git log --oneline --graph develop \| head -5` | Виден коммит слияния `merge: close <ID>`; изменения ветки задачи реально попали в основную ветку (слияние не пустое, не «ветка в саму себя») | [ ] |
| 3 | Открыть итоговый отчёт о расходе в закрытой задаче (`usage_report.md`) и сверить время начала окна с первым коммитом задачи | Окно расхода непустое и корректное, а не пометка «определить не удалось» | [ ] |

**Заметки:** [Оставьте пустым или запишите наблюдения]
