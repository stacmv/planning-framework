## How to use

Этот чек-лист проведёт вас по ручной проверке возможности шаг за шагом.

1. Прочитайте каждый раздел целиком перед началом, чтобы понимать, чего ожидать.
2. Выполните предусловия, перечисленные в начале каждой проверки — если предусловие выполнить не удаётся, остановитесь и спросите разработчика, прежде чем продолжать.
3. Выполняйте шаги по порядку. После каждого шага сверьтесь с колонкой «Ожидаемый результат» и запишите, что произошло на самом деле, в колонку «Результат».
4. Ставьте `[x]`, если шаг отработал как ожидалось, и оставляйте `[ ]`, если что-то пошло не так.
5. Строку «Заметки» в конце каждой проверки используйте для всего необычного, даже если проверка пройдена.
6. Закончив все проверки, верните этот документ разработчику.
