# Широкая таблица на шесть колонок (данные TC-019, шаг 5)

Документ для шага 5 TC-019. Он повторяет форму трекера статусов из
`test_plan.md`: шесть колонок, двадцать строк данных, в колонке «Замечание»
намеренно длинный текст — на нём и проверяется перенос по словам.

Что смотреть на шаге 5:

- колонки выровнены, границы ячеек различимы;
- длинный текст в ячейке переносится по словам, а не растягивает страницу;
- прокрутка вбок, если она нужна, принадлежит таблице, а не странице целиком.
