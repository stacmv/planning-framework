## Как пользоваться

Этот чек-лист проведёт вас через ручную проверку одной возможности.

1. Прочитайте весь тест до начала, чтобы понимать, чего ожидать.
2. Подготовьте всё, что перечислено в разделе «Предварительные условия». Если
   что-то подготовить не получается — остановитесь и спросите разработчика,
   не продолжайте.
3. Выполняйте шаги по порядку. После каждого сверьтесь с колонкой «Ожидаемый
   результат» и запишите в колонку «Результат», что произошло на самом деле.
4. Ставьте `[x]`, если шаг отработал как ожидалось, и оставляйте `[ ]`, если
   что-то пошло не так.
5. В строке «Замечания» внизу каждого теста запишите всё необычное — даже если
   тест в целом прошёл.
6. Закончив все тесты, верните этот документ разработчику.

Команды вида `/pf`, `/pf-idea-critique`, `/pf-idea-verdict` набираются внутри
сессии Claude Code в каталоге проекта — это интерфейс проверяемого инструмента.
Файлы вроде `idea.md` или `verdict.md` инструмент создаёт сам; вы их открываете
и читаете.

Для тестов, у которых указаны подготовленные данные, выполните один раз:
`node setup.mjs` из каталога `test-data` — он разложит файлы по указанным ниже путям.
