# Idea: weekly-notes-digest

## Pain & Evidence
Заметки копятся и не перечитываются. Свидетельство: владелец не открывал папку
заметок больше месяца.

## Analogs
Ручное перечитывание; готовые сервисы заметок со сводками.

## Prior Art
Встроенные обзоры в приложениях заметок.

## Differentiation / USP
Работает локально по обычной папке файлов, без переноса в чужой сервис
(допущение, см. `open_questions.md` #1).

## MVP
Скрипт, собирающий заголовки за неделю в один файл.

## Cost (Effort)
Вечер.

## Risks
Сводка окажется бесполезной, если заметки слишком разнородны.

## Lenses Applied
5 почему.
