# Test Plan: Add Testing, QA and Close Issue Phases

**Issue:** 20260630-improve-add-testing-qa-close-phases
**Date:** 2026-06-30

## Overview

Verify that the five new/updated skills (`/pf-execute` branch creation, `/pf-test`, `/pf-qa`, `/pf-qa-setup`, `/pf-close`) and the updated `/pf` orchestrator behave correctly at each lifecycle stage. Also verify template changes (`test_plan.md`, `manual_test_checklist.md`, `qa_report.md`).

**Scope:** Skill files (SKILL.md), template files, and end-to-end skill execution in a real project context.

## Prerequisites

- A test project with a Planning Framework v3.0 install
- At least one open issue with `implementation_plan.md` present (IMPL_PLAN stage done)
- Node.js project recommended for auto-test runner detection (or PHP/Python alternative)
- `.qa-workflow.md` present for QA tests; intentionally absent for fallback tests

---

## Test Cases

### Category 1: `/pf-execute` — Branch Creation

### TC-001: Creates issue branch before first code commit

**Type:** Manual
**Description:** Verifies `/pf-execute` creates the git branch as its first action.

**Preconditions:**
- Active issue with `implementation_plan.md` present
- Issue branch does NOT exist yet

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run `/pf-execute` in project | First output mentions branch creation |
| 2 | Check git branches | `issue/ISSUE-ID` branch exists |
| 3 | Check current branch | Active branch is `issue/ISSUE-ID` |

**Expected Outcome:** Branch created, agent proceeds to task execution on issue branch.
**Priority:** Critical

---

### TC-002: Checks out existing branch without error

**Type:** Manual

**Preconditions:**
- Active issue with `implementation_plan.md` present
- Issue branch already exists

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|

| 2 | Check current branch | Active branch is `issue/ISSUE-ID` |
| 3 | Observe execution | Proceeds to task execution normally |

**Expected Outcome:** Clean checkout, no duplicate branch error.
**Priority:** High

### TC-004: Failing auto tests block TESTING stage

**Type:** Manual
**Description:** When auto tests fail, `manual_test_checklist.md` must NOT be created.

**Preconditions:**
- Active issue with `test_plan.md` containing at least one `Type: Auto` test case
- At least one auto test in the project is currently failing

**Steps:**

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Run `/pf-test` | Skill runs test suite |
| 2 | Observe output | Failure summary reported |
| 3 | Check issue folder | `test_results.md` created, `manual_test_checklist.md` NOT created |
| 4 | Run `/pf` | Stage shown as IMPL_PLAN (not TESTING) |

**Expected Outcome:** Pipeline does not advance; agent must fix tests and re-run.
**Priority:** Critical
