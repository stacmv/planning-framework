# Specs: env-dump.sh

## Overview

`env-dump.sh` — bash-скрипт без аргументов, печатающий текущее окружение
процесса (`env`), пропущенное через `sort`.

## Behavior

- Реализация: `env | sort`.
- Код выхода всегда 0, если только `env`/`sort` не завершились с ошибкой.

## Out of scope

- Фильтрация чувствительных переменных (токенов, паролей).
- Вывод в форматах, отличных от `ИМЯ=значение`.
