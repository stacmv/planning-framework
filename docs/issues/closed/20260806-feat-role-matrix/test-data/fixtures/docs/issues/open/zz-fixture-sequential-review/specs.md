# Specs: retry-wrapper.sh

## Overview

`retry-wrapper.sh <cmd> [args...]` запускает переданную команду; если она
завершается ненулевым кодом, повторяет попытку до 3 раз с задержкой 2
секунды между попытками.

## Behavior

Максимальное число попыток — ровно 3. После третьей неудачной попытки
`retry-wrapper.sh` завершается с кодом последней неудачной попытки.

## Planted contradiction (for reviewer to find)

Максимальное число попыток — ровно 5, а не 3: задержка между попытками
растёт экспоненциально (2с, 4с, 8с, 16с), а не остаётся постоянной 2
секунды, как сказано в разделе Behavior выше. Это прямое противоречие двух
соседних абзацев одного документа, которое первый ревьюер (`haiku`) обязан
найти и которое актор `write` (Claude) должен исправить автоматически,
прежде чем документ уйдёт второму ревьюеру (`codex`).

## Out of scope

- Настраиваемое число попыток через аргумент командной строки.
- Логирование каждой попытки в файл.
