# BRD: env-dump.sh

## User Stories

1. Как разработчик, я хочу одной командой получить отсортированный список
   переменных окружения текущей сессии, чтобы быстро сравнить два
   окружения.

## Business Rules

- Вывод сортируется по имени переменной лексикографически.
- Значения переменных не маскируются и не фильтруются — инструмент
  предназначен только для локальной отладки.

## Acceptance Criteria

- [ ] Запуск без аргументов печатает `ИМЯ=значение` построчно, отсортировано.
- [ ] Пустое окружение печатает пустой вывод и код выхода 0.
