Улучшить UX установки/обновления фреймворка с помощью make, а также сделать TUI для новых проектов и для новых пользователей фреймворка, не знакомых с ним.

Дополнение (после первого закрытия issue): TUI должен быть доступен глобально из любой директории — установить шим `pf` в директорию на PATH. Также нужен однокомандный кросс-платформенный (Windows/Linux/macOS) установщик, который пользователь копирует из README на GitHub — он должен склонировать/обновить фреймворк в `~/.claude/planning-framework`, проверить зависимости (git, node) с понятной ошибкой при отсутствии, и установить шим/скиллы. Повторный запуск той же команды обновляет существующую установку (`git pull` + переустановка шима/скиллов).
