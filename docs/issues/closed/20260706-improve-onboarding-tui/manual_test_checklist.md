# Чек-лист ручного тестирования

**Название функции:** Глобальный шим `pf`, однокомандный установщик (`install.sh` / `install.ps1`), README — реопен (Tasks 6–9, AC-6/7/8)

**Дата:** 2026-07-10 (реопен); TC-005..010 от 2026-07-06 (исходный scope, `make tui`) сохранены ниже для полноты

## Как пользоваться этим чек-листом

1. Прочитайте раздел целиком перед началом, чтобы понимать, чего ожидать.
2. Подготовьте всё, что указано в разделе "Предварительные условия" вверху каждого теста. Если не получается что-то подготовить — остановитесь и уточните у разработчика, прежде чем продолжать.
3. Выполняйте шаги по порядку. После каждого шага сверьте фактический результат с колонкой "Ожидаемый результат" и запишите, что произошло на самом деле, в колонку "Результат".
4. Отмечайте чекбокс `[x]`, если шаг прошёл как ожидалось, или оставляйте `[ ]`, если что-то пошло не так.
5. Используйте строку "Заметки" в конце каждого теста, чтобы зафиксировать что-то необычное, даже если тест в целом прошёл успешно.
6. По завершении всех тестов передайте этот документ разработчику.
