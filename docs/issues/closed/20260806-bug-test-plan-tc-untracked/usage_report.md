## Как посчитано

Тарифы взяты из скилла `claude-api` (таблица моделей), не по памяти:

| Модель | Input $/Mtok | Output $/Mtok | Cache write | Cache read |
|---|---|---|---|---|
| `claude-opus-5` | $5.00 | $25.00 | $10.00 | $0.50 |

Два допущения, оба влияют на итог и потому названы явно:

1. **Cache write = 2× input, а не 1.25×.** Базовая ставка записи в кэш — 1.25× при TTL
   5 минут и 2× при TTL 1 час. Эта сессия работает с **часовым** TTL, поэтому взят
   множитель 2×. При 5-минутном TTL итог был бы ~$56.5.
2. **Sonnet считается по интро-тарифу** ($2/$10 вместо $3/$15), действующему до
   2026-08-31. Сегодня 2026-08-11 — попадает в окно.
