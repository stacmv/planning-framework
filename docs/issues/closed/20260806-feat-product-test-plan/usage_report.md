## Как посчитано

Ставки — из скилла `claude-api` (кэш таблицы моделей на 2026-06-24). Он
установлен не в `~/.claude/skills/`, а в bundled-skills текущей версии CLI, из-за
чего первичный поиск по файловой системе его не нашёл; вызов по имени сработал.

| Модель | Вход $/Mtok | Выход $/Mtok |
|---|---|---|
| `claude-opus-5` | 5.00 | 25.00 |
| `claude-sonnet-5` | 2.00 | 10.00 |

`claude-sonnet-5` посчитан по **вводной** цене ($2/$10 вместо базовых $3/$15) —
она действует до 2026-08-31, то есть на дату закрытия применима. При расчёте по
базовой ставке Sonnet-часть составила бы примерно $44.3, а общая сумма — около
$222.9.

Множители кэша (`shared/prompt-caching.md`): чтение из кэша — 0.1× входной
ставки, запись в кэш — 2× при часовом TTL (в этой сессии он часовой; при
пятиминутном было бы 1.25×, и тогда Opus-часть вышла бы примерно на $11.5
дешевле).

**Основная статья расхода — чтение из кэша, а не генерация:** 382M токенов
кэш-чтений против 784K выходных. Это ожидаемо для длинной сессии с большим
контекстом: каждый запрос перечитывает накопленную историю, но по цене 0.1× от
входной ставки. Отключение кэша сделало бы те же 382M токенов десятикратно
дороже.

**Разделение по моделям отражает распределение работы:** `claude-opus-5` —
оркестрация и решения (включая пять проходов ревью и разбор находок),
`claude-sonnet-5` — субагенты реализации, ревью и генерации документов, согласно
конвенции проекта (субагентам на /pf-процесс — sonnet).

`<synthetic>` — не модель, а служебная запись транскрипта с нулевым расходом;
оставлена в таблице ради полноты дедупликации, в итог не входит.
