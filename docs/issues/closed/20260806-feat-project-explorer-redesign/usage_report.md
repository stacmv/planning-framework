  работу по данному issue.** За три недели сюда попали параллельные задачи —

- **Основная часть суммы — чтение кэша, а не генерация.** У `claude-sonnet-5`
  742 млн токенов чтения кэша против 995 тыс. выходных: ~$148 из ~$172 по этой
  модели — это перечитывание резидентного контекста на каждом ходу.
- **Cache write считан по тарифу 5-минутного TTL.** Если часть записей шла с
  часовым TTL, их реальная цена вдвое выше базового input, и итог занижен;
  различить TTL по транскрипту нельзя.
