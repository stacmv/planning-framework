# QA Workflow

**Project:** Planning Framework
**Version:** 4.0
**Last Updated:** 2026-08-14

## Required Checks

- [ ] `node --check scripts/pf-cli.mjs` passes.
- [ ] `make test` passes, including the fresh-project and v2 migration tests.
- [ ] `node --test tools/onboarding-tui/test/*.test.js test/pf-cli.test.mjs` passes directly.
- [ ] `git diff --check` reports no whitespace errors.
- [ ] No changed skill contains a disabled or obsolete instruction block.
- [ ] `CHANGELOG.md` describes framework-facing changes.
- [ ] The worktree is clean before release and the branch is an ancestor of `develop` where applicable.

## Scope

The framework is a dependency-free Node.js CLI plus Markdown skills and internal Node.js tools.
Consumer projects require `git` and Node.js 18 or newer. The CLI invokes `git` with argument arrays
and performs file operations through Node.js APIs; it does not require Bash, `sh`, `sed`, `awk`,
`grep`, `find`, `cp`, `rm`, `rsync`, or `shellcheck`.

## Release Gate

The framework version is `PF_VERSION` in `scripts/pf-cli.mjs`. Every `skills/*/SKILL.md` frontmatter
version must match it. Update the README badge, templates, changelog, and Codex/Claude adapter
documentation together with a major or minor release.
