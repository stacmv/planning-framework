# QA Workflow

Quality assurance checklist that must pass before closing any issue.

## All Issues

- [ ] **Linting/formatting passes** - Code style consistent
- [ ] **All existing tests pass** - No regressions
- [ ] **New tests added** - New functionality is tested
- [ ] **Documentation updated** - README, guides, comments as needed
- [ ] **No security vulnerabilities** - Check for common issues (injection, XSS, etc.)

## Feature Issues (feat/improve)

- [ ] **Integration tests pass** - If applicable to this project
- [ ] **Examples updated** - If example code exists
- [ ] **User-facing docs updated** - If feature is user-visible

## Bug Issues

- [ ] **Failing test created** - Test that reproduces the bug
- [ ] **Test now passes** - After bug fix
- [ ] **Regression test added** - Prevent future recurrence

## Planning Framework Specific

- [ ] **Templates tested** - If templates modified, test with fresh project
- [ ] **Scripts tested** - If scripts modified, test all code paths
- [ ] **Documentation consistent** - No conflicting instructions
- [ ] **Examples work** - All code examples run successfully
